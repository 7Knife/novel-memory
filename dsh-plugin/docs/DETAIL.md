# Novel Memory detail

Novel Memory adds a lightweight entity-review workflow on top of Basic Memory for novel writing.

- Trigger review at scene end, chapter finalization, an explicit setting change, or manual request.
- Scope review to entities that actually appear in or are referenced by the current scene.
- Produce `new`, `update`, or `status_progression` suggestions with paragraph and quote evidence.
- Keep unconfirmed suggestions in a pending queue; nothing is written into Basic Memory until you confirm it.
- Keep self-cognition local to an entity note and read it only when that entity is needed.

This plugin does not provide a global memory store, global self-cognition injection, a web UI, external agent dispatch, or automatic setting changes.
